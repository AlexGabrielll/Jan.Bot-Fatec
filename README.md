# Jan.Bot — FATEC

## Sobre o projeto

O **Jan.Bot** é um projeto desenvolvido no contexto acadêmico da FATEC, com foco na utilização de Inteligência Artificial Generativa por meio de um modelo de linguagem executado localmente.

A proposta é disponibilizar um bot capaz de interagir com o usuário utilizando uma **LLM local**, mantendo o processamento concentrado no ambiente do **Jan**.

##  Modelo de IA

O projeto utiliza o seguinte modelo de linguagem:

- **LLM:** `Jan-code-4b-Q4_K_M`

O modelo é executado localmente através do **Jan**, uma plataforma open source que permite baixar e executar modelos de linguagem no próprio computador. 

##  Hospedagem / Execução

Tanto o **servidor responsável pela comunicação da aplicação** quanto a **LLM** são executados por meio do aplicativo **Jan**.

### Ambiente principal

| Componente | Tecnologia |
|---|---|
| Modelo LLM | `Jan-code-4b-Q4_K_M` |
| Plataforma de execução | **Jan** |
| Servidor | **Jan** |
| Processamento da IA | Local |

Essa arquitetura permite trabalhar com o modelo sem depender diretamente de uma API de IA em nuvem, utilizando o ambiente local disponibilizado pelo Jan. citeturn996528search4

##  Objetivo

O projeto tem como objetivo explorar a integração entre uma aplicação de bot e uma **LLM local**, utilizando o Jan como ambiente de execução do modelo e da comunicação necessária para o funcionamento da aplicação.

##  Tecnologias

As principais tecnologias e componentes envolvidos são:

- Inteligência Artificial Generativa
- LLM (`Jan-code-4b-Q4_K_M`)
- Jan
- Bot / aplicação de interação
- Execução local
